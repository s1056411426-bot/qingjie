# IconPark 原版图标映射

来源：[IconPark 官方图标库](https://iconpark.oceanengine.com/official)、[官方源码](https://github.com/bytedance/IconPark)。使用官方包 @icon-park/svg 1.4.2，Apache-2.0 授权。

直接调用官方 SVG 导出函数，使用 outline 主题、原生 48×48 viewBox、4 单位线宽和 currentColor。路径、形状及比例没有手工改画；仅移除 XML 声明，显示时设置尺寸及无障碍属性。应用 Logo 使用用户原图。

运行 npm run icons 可重新生成。选中的 SVG 本地打包，运行时无需访问网站。
