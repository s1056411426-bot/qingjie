# 图标与品牌间距（0.1.2）

## 参考依据

- [微软 Windows 图标构建规范](https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-construction)：ICO 应包含多个尺寸；Windows 优先匹配准确尺寸，缺失时向下缩放更大的图标。
- [Microsoft Fluent 2 布局](https://fluent2.microsoft.design/layout)：以 4 像素为基础组织间距，并考虑图标内部留白和视觉对齐。
- [Electron Tray 平台说明](https://www.electronjs.org/docs/latest/api/tray)：Windows 推荐使用 ICO 文件。

## 本次采用的参数

- 用户原图 `assets/logo-source.png` 保持不变。派生图标按 alpha ≥ 128 的主体边界居中，主体占画布约 94%，四周各约 3% 光学留白；裁切边缘的淡阴影平滑淡出。原来的主体占比约 77%，新图标主体宽高增加约 22%。94% 是本项目的视觉调整值，并非微软规定的统一比例。
- 品牌图标容器保持 48 × 48 CSS px；图文容器间距从 12 调整为 4 CSS px，文字向左移动 8 CSS px。150% 缩放下对应 12 个物理像素。
- ICO 包含 16、20、24、30、32、36、40、48、60、64、72、80、96、128、256 共 15 个尺寸，覆盖微软列出的 100%–400% 缩放所需尺寸。
- Windows 窗口、托盘使用同一多尺寸 ICO。文件单独放在发布包 resources 目录，供 Windows 原生 API 读取；取消托盘固定压缩到 20 px 的处理。
- EXE 使用相同 ICO；界面使用相同构图的 1024 px PNG。保持原始图案、颜色和透明背景，不添加额外底板。

## 验证边界

本次重点验证品牌间距、图标主体占比、ICO 各尺寸、EXE 内嵌资源、发布包路径、便携程序启动，以及当前 Windows 150% 缩放下原生托盘创建。其余缩放比例提供了对应资源，但未逐一切换系统设置实测。Mac 二进制仍未构建验证。

## 0.1.3 微调

按用户指定，将品牌文字（中文及英文）在 0.1.2 基础上向右移动 5 CSS px，图文容器间距从 4 改为 9 CSS px。图标大小及其资源保持不变。
