# 轻截 0.1.1 验收说明

环境：Windows 10 x64，屏幕缩放 150%，Electron 45.3.3。软件为未签名开发版本。

2026-11-19 的 0.1.2 更新收紧品牌图文间距、放大图标有效主体，并补齐 Windows 多尺寸 ICO。此次核验图标资源、EXE 内嵌资源、150% 缩放下界面及任务栏、原生托盘创建和便携程序启动。设计依据与参数见《图标与品牌间距.md》。下列功能测试记录来自此前的 0.1.0 验证。

0.1.3 微调：品牌中英文文字在 0.1.2 基础上向右移动 5 CSS px；已在打包界面测得位移为 5 px、图标位移为 0 px。便携启动验证通过后交付。

0.1.4 更新：功能图标直接采用 IconPark 官方 SVG，映射见《IconPark图标映射.md》。本次重新通过桌面端到端验证：工作台、标注、撤销重做、剪贴板、历史、JPG 保存、贴图、离线 OCR、裁剪、真实截图选区、设置页面；未发现渲染脚本错误。

## 已完成的本地验证

- 7 项自动测试：高 DPI 选区映射、选区边界与非法输入、不同滚动距离的逐像素重建、静止与无关帧拒绝、重复图案歧义拒绝、PNG 输入限制、长图内存尺寸限制。
- 桌面端到端测试：工作台、标注与文字、撤销 / 重做、裁剪及撤销、图片剪贴板、JPG 文件头、历史记录、图片置顶、离线 OCR、真实屏幕框选及设置页面。
- 高 DPI 实测：460 × 300 逻辑像素选区导出为 690 × 450 物理像素。
- 中英文 OCR 样例：识别出 “Capture a little inspiration.”、“让每一个重点更清晰” 和 “QINGJIE 2026”。识别不是百分之百准确；样例中的低对比图块文字存在漏识别。
- 真实滚动测试：手动滚动测试页面，4 帧自动拼接成 870 × 1455 像素长图，符合 150% DPI 下预期尺寸。
- 在打包后的 EXE 重复桌面验证，确认解包后的工作线程依赖和本地模型能够加载。
- 便携 EXE 另行测试解压启动流程。Windows 8.3 短路径与长路径使用 canonical realpath 比较，保持 IPC 来源限制。

运行验证命令：

```sh
npm test
npm run test:app
node scripts/scroll-smoke.cjs
node scripts/portable-smoke.cjs
```

测试数据和原始测试截图保留在开发工作区 `.test-data`、`.test-output`；不包含在源码压缩包中。交付的界面预览只展示轻截本身和人工测试图片。
